# Componente de Investigação Científica

Espaço reservado aos artefactos científicos da unidade curricular e futuro artigo:

- `literature-review/`: revisão bibliográfica sobre agentes LLM com *tool calling* sobre dados estruturados.
- `methodology/`: protocolo experimental comparando Configurações A (LLM sem fontes), B (uma fonte) e C (cruzamento API + Excel com validação e RBAC).
- `test-dataset/`: perguntas de referência validadas e dados sintéticos anonimizados para testes sem exposição de dados reais.
- `experiments/`: resultados e métricas (exatidão numérica, completude, fontes citadas, alucinações, segurança RBAC).
